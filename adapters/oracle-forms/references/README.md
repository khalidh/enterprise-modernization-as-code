# Oracle Forms Reference Files

Place the genuine `HELLO_WORLD.fmb` reference form in this directory when it is available.

Do not rename or reuse the neighboring `oracle-forms-plugin/generated/HELLO_WORLD.fmb` as this reference: its associated XML describes `CUSTOMER_FORM` and does not contain the MVP `BTN_BONJOUR` object.

Keep reference FMB files unchanged. Validate compatibility by converting the matching XML to FMB and compiling it with the Oracle Forms tools before declaring Oracle Forms compatibility.
